## Defects reproduced

1. `canonicalRequestHash` used `JSON.stringify(request, Object.keys(request).sort())` — the replacer array drops nested keys, so changed `target.actor_name`/`selection.ids`/overrides produced the same hash
2. All jobs shared `store.rootDir` — no per-run isolation
3. No deadline timer from `timeout_ms`
4. Root lock was check-then-write, not atomic
5. Cancel set `cancelRequested` but `runExecution`'s catch block overwrote with `error`

## Files changed

| File | Change |
|------|--------|
| `src/runner-api/job-store.ts` | Recursive `sortKeysDeep`, atomic `O_CREAT|O_EXCL` lock, `workDir(runId)` |
| `src/runner-api/job-manager.ts` | Per-run workspace, deadline timer, cancel guard, error envelope |
