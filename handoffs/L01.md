## Defect reproduced

The producer (`src/report/native-export.ts`) emits camelCase fields:
`nativeStatus`, `ancestorTitles`, `title`, `requirementId`.

The worker (`src/runner-api/native-worker.ts`) passed `nativeExport.assertions`
directly to the wire type which expects snake_case (`native_status`, `full_title`, etc.).

The summarizer (`src/runner-api/summarize.ts`) reads `native_status` to count
failures. Since the camelCase field name didn't match, `nativeFailedCount` was
always 0, producing `summary.result = "pass"` even for real FAIL assertions.

Additionally, `summarizeResult` checked `nativeFailedCount > 0` BEFORE
`scenarioInconclusive`, flattening INCONCLUSIVE scenarios to FAIL.
